NotesPanel: Alpha Readiness Review

5 fixes needed before Ambient users land here — ranked by user impact

Blocking 1. Dev-facing error message

Current text: "Check that NEXT_PUBLIC_VAULT_ENABLED=true is set". A new user will close the tab. Fix: "Knowledge base is offline. Reload the page or contact support."

Blocking 2. Empty state gives no guidance

Current: "No notes yet. Click + to create one." New users coming from Ambient expect to SEE their notes here automatically. Need an empty state that explains: "Connect Ambient to sync your daily notes here" with a setup CTA.

High 3. No confirmation before note deletion

Delete button triggers on hover click — one mis-click wipes a note permanently. Add a simple confirmation modal. This will absolutely happen to early users and destroy trust.

High 4. Sessions folder is unexplained

Users see "All Notes" and "Sessions" with no explanation of what Sessions are. Add a tooltip: "Auto-saved snapshots of your Claude Code sessions." Without this, users won't understand the structure.

Medium 5. Search mode needs a label

Semantic/keyword toggle only appears after typing. Show it always, and add a brief tooltip explaining what "semantic search" means.

Plan impact: Items 1 + 2 are must-fix before any Ambient user lands here. Items 3-5 can be fixed in parallel with building the Ambient sync. Estimate: 1 focused day of polish work.
