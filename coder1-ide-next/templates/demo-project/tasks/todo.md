## Development Workflow Example

When working on a new task:

1. **Plan**: Add task to this file with subtasks
2. **Implement**: Work through subtasks, marking complete as you go
3. **Review**: Check your work against requirements
4. **Document**: Add notes about decisions made
5. **Update**: Move task to "Completed" section
