Get started in minutes

Already have Claude Code? You're almost there.

1

Install Claude Code

If you haven't already, install Anthropic's official CLI.

npm install -g @anthropic-ai/claude-code
2

Authenticate

Login with your Anthropic account. Your subscription is recognized.

claude auth login
3

Install Johnny5

Add the Johnny5 agent interface. Start building autonomously.

npm install -g johnny5-agent
