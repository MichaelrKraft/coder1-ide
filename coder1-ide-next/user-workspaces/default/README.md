# Welcome to Coder1 IDE! 🚀

This is your personal workspace where you can create and edit files.

## Getting Started

1. **Create Files**: Use the file explorer on the left to create new files
2. **Edit Code**: Click on any file to open it in the Monaco editor
3. **Terminal**: Use the integrated terminal at the bottom to run commands
4. **AI Assistance**: Claude Code is here to help you build anything!

## Sample Files

- `index.html` - A starter HTML template
- `app.js` - A sample JavaScript file
- `styles.css` - Basic CSS stylesheet

## Tips

- Press **Cmd/Ctrl + S** to save files
- Use the **Terminal** to run your code
- Ask **Claude** for help with any coding questions!

Happy coding! ✨
