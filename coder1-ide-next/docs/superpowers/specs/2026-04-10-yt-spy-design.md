# YT-Spy Skill — Design Spec & Implementation Plan

## Context

Mike is a YouTube creator in the Claude Code niche. He wants to move fast when competitors post Claude Code videos — piggybacking on trending topics with his own original take, ideally being one of the first commenters on the competitor video. This skill automates the entire pipeline: detect → analyze → script → thumbnail brief → comment → alert.

---

## Design Spec

### Overview

**Skill name:** `yt-spy`  
**Invoked as:** `/yt-spy` (monitor run) or `/yt-spy launch` (open Clickly with pending thumbnail)  
**Scheduled via:** `CronCreate` every 15 minutes  
**Skill location:** `~/.claude/skills/yt-spy/`

### Channels Monitored (4 total)
- Nate Herk
- Mark Kashef
- Jay E / RoboNuggets
- Chase AI

Channel IDs to be resolved during implementation via YouTube Data API or channel URL lookup.

### Detection Filter
Only process videos where title OR description contains Claude Code keywords:
`"Claude Code"`, `"claude code"`, `"Claude.ai Code"`, `"claude-code"`

Note: "Coder" alone is too broad and will false-positive. Stick to explicit "Claude Code" variants only.

### End-to-End Flow (per cron run)

```
CronCreate (every 15 min) → claude -p "Run /yt-spy"
  → Load state.json (seen video IDs per channel)
  → For each of 4 channels:
      Fetch RSS: https://www.youtube.com/feeds/videos.xml?channel_id=CHANNEL_ID
      Parse XML → get newest videos
      Skip any video ID already in state.json
      Check title/description for Claude Code keywords
      → If match:
          1. Fetch transcript (mcp__youtube__get_transcript)
          2. Generate Kallaway script + original angle (Claude)
          3. Generate thumbnail brief (Claude)
          4. Save to pending/ package
          5. Post comment (helpers/post-comment.js)
          6. Send email (helpers/send-email.js)
  → Update state.json with all processed IDs
```

### Script Generation

Inputs to Claude:
- Competitor video transcript
- `~/.claude/skills/video-script-writer/kallaway-patterns.md`
- `~/Desktop/Businesses/mike-drop-content/foundation/01-audience-avatar.md` (Dave persona)
- `~/Desktop/Businesses/mike-drop-content/foundation/02-creator-persona.md` (Mike's voice)
- `~/Desktop/Businesses/mike-drop-content/foundation/03-niche-intelligence-report.md`

Output:
- Suggested video title
- Hook (first 30 seconds verbatim)
- Full script with section timestamps
- Original angle explanation (what the competitor missed or underexplained)
- Dual persuasion layer notes (Cialdini + Chase Hughes)

Voice rules:
- Signature phrases: "Here's the thing," "No cap," "100%," "It's an absolute banger," "Automatically," "Baller"
- REMOVED: "Hard stop" (no longer part of Mike's brand — April 2026)
- Anti-phrases: NEVER "smash that like," NEVER "In today's video," NEVER hedge words
- Teaching style: state truths ("When you do this...") not suggestions ("If you try...")
- Dave lens: 35-48 corporate professional, 45 min/night, fear of financial risk

### Thumbnail Brief

Generated by Claude alongside the script. Saved to `pending/<slug>/thumbnail-brief.md`:
- Hook text overlay (short, punchy)
- Visual concept / background setting
- Emotional expression / body language
- Props or on-screen elements
- Color direction
- `/yt-spy launch` invokes `clickly-thumbnail-creator` with this pre-loaded

### Auto-Comment

- Genuine, specific to the video topic
- Mike's voice without being spammy or promotional
- No channel plugging (profile does the work)
- Short (2-4 sentences)
- Posted via `helpers/post-comment.js` → YouTube Data API v3 `commentThreads` endpoint
- OAuth 2.0, scope: `youtube.force-ssl`
- Tokens stored in `~/.claude/skills/yt-spy/.env`
- If quota exceeded: logs warning, continues with rest of pipeline

### Email Alert

**To:** Poolkraftllc@gmail.com  
**Subject:** `[YT-SPY] New Claude Code video: "<Title>" — <Channel>`  
**Sent via:** nodemailer + Gmail SMTP App Password

**Body includes:**
- Video title + link
- Time since posted
- 2-sentence video summary
- Your original angle (the gap Claude found)
- Full Kallaway script
- Thumbnail brief
- Comment posted confirmation + link
- Instructions: "Run `/yt-spy launch` to open Clickly"


### File Structure

```
~/.claude/skills/yt-spy/
  SKILL.md                    ← main skill instructions
  package.json                ← googleapis, nodemailer deps
  helpers/
    post-comment.js           ← YouTube OAuth comment poster
    send-email.js             ← nodemailer emailer
    setup-oauth.js            ← one-time OAuth setup wizard
  state.json                  ← persisted seen video IDs
  pending/                    ← generated packages waiting for /yt-spy launch
    YYYY-MM-DD-<slug>/
      script.md
      thumbnail-brief.md
      video-meta.json
  .env.example                ← credential template
  .env                        ← actual credentials (gitignored)
```

### One-Time Setup Requirements

1. Google Cloud Console: enable YouTube Data API v3, create OAuth 2.0 credentials → download `client_secret.json`
2. Run `node ~/.claude/skills/yt-spy/helpers/setup-oauth.js` → browser auth flow → stores tokens in `.env`
3. Gmail App Password: Google Account → Security → App Passwords → generate 16-char password → store in `.env`
4. `cd ~/.claude/skills/yt-spy && npm install`
5. Resolve YouTube channel IDs for all 4 channels
6. Run `CronCreate` to schedule every 15 minutes

## Implementation Plan

### Step 1 — Resolve channel IDs
Look up YouTube channel IDs for: Nate Herk, Mark Kashef, Jay E/RoboNuggets, Chase AI.
Tool: fetch their channel pages or use YouTube Data API search.

### Step 2 — Scaffold skill directory
Create `~/.claude/skills/yt-spy/` with all files listed in the file structure above.

### Step 3 — Write SKILL.md
Full skill instructions for Claude: RSS polling logic, Claude Code keyword detection, transcript fetching via `mcp__youtube__get_transcript`, script generation prompt (loading foundation docs), thumbnail brief generation, calling helper scripts, state.json update logic. Include `/yt-spy launch` sub-command instructions.

### Step 4 — Write helpers/setup-oauth.js
One-time interactive script that:
- Reads `client_secret.json`
- Opens OAuth consent URL in browser
- Exchanges code for tokens
- Writes `YOUTUBE_ACCESS_TOKEN`, `YOUTUBE_REFRESH_TOKEN`, `YOUTUBE_CLIENT_ID`, `YOUTUBE_CLIENT_SECRET` to `.env`

### Step 5 — Write helpers/post-comment.js
- Reads OAuth tokens from `.env`
- Accepts videoId and commentText as CLI args
- Calls YouTube Data API v3 `commentThreads.insert`
- Handles token refresh automatically
- Exits 0 on success, 1 on failure (quota or error)

### Step 6 — Write helpers/send-email.js
- Reads Gmail SMTP credentials from `.env`
- Accepts video metadata + script content via stdin or temp file
- Sends HTML-formatted email to Poolkraftllc@gmail.com
- Exits 0 on success

### Step 7 — Write package.json + .env.example
Dependencies: `googleapis`, `nodemailer`, `dotenv`  
`.env.example` documents all required variables with descriptions.

### Step 8 — Write state.json (initial)
Empty state with all 4 channel keys initialized.

### Step 9 — Set up CronCreate
Schedule: every 15 minutes  
Command: `cd ~ && claude -p "Run the yt-spy skill to check all 4 channels for new Claude Code videos"`

### Step 10 — Write spec file to proper location
Copy this spec to: `~/autonomous_vibe_interface/coder1-ide-next/docs/superpowers/specs/2026-04-10-yt-spy-design.md`

### Step 11 — Test dry run
Run skill manually once with a known recent Claude Code video to verify:
- RSS fetch works
- Claude Code detection fires
- Transcript fetches
- Script generates correctly (check voice, Kallaway structure, original angle)
- Comment posts (verify on YouTube)
- Email arrives at Poolkraftllc@gmail.com
- state.json updates
