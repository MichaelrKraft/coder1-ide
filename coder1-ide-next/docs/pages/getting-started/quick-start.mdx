## Installation

<Steps>
  <Step title="Clone the Repository">
```bash
git clone https://github.com/MichaelrKraft/coder1-ide.git
cd coder1-ide/coder1-ide-next
```

<Callout type="info">
The Coder1 IDE is in the `/coder1-ide-next` subdirectory of the main repository.
</Callout>
  </Step>
  
  <Step title="Install Dependencies">
```bash
npm install
```

This installs all required packages: Next.js 14 (React framework), Monaco Editor (code editing), Socket.IO (real-time communication), XTerm.js (terminal emulation), and Zustand (state management).
  </Step>
  
  <Step title="Configure Claude Code CLI">
**Install Claude.app**:

1. Download from [claude.ai](https://claude.ai)
2. Open Claude.app
3. Go to menu: **Claude → Enable Claude Code**

**Verify installation**:
```bash
claude --version
# Should output: claude-code vX.X.X
```

**Configure Coder1**:
```bash
echo "ENABLE_CLI_PUPPETEER=true" >> .env.local
echo "CLAUDE_CLI_PATH=/opt/homebrew/bin/claude" >> .env.local
```
  </Step>
  
  <Step title="Start the Development Server">
```bash
npm run dev
```

The IDE will be available at:
- **Main IDE**: [http://localhost:3001/ide](http://localhost:3001/ide)
- **Homepage**: [http://localhost:3001](http://localhost:3001)

<Callout type="success">
You should see: **"🚀 Coder1 IDE - Unified Server Started"** with the server URL.
</Callout>
  </Step>
</Steps>

## What Just Happened?

Let's break down the magic:

### 1. Git Worktrees

Each agent worked in an **isolated directory**:
```bash
.claude-parallel-dev/
└── team-xyz/
    ├── frontend/   # Branch: claude-agent/team-xyz/frontend
    ├── backend/    # Branch: claude-agent/team-xyz/backend
    └── testing/    # Branch: claude-agent/team-xyz/testing
```

**Benefits**:
- ✅ No merge conflicts during development
- ✅ Agents don't interfere with each other
- ✅ Easy to review each agent's work separately
- ✅ Safe to discard unwanted changes

### 2. Claude CLI Processes

Real Claude Code CLI instances were spawned via PTY:
```typescript
const frontendAgent = spawn('/opt/homebrew/bin/claude', [], {
  cwd: '.claude-parallel-dev/team-xyz/frontend',
  env: { CLAUDE_AGENT_ROLE: 'frontend', CLAUDE_TASK: '...' }
});
```

**Why This Matters**:
- 💰 Uses your Claude Pro subscription (\$20/month you already have)
- 🚀 No API costs (would be \$200-500/month otherwise)
- 🎯 Real Claude capabilities, not limited API wrapper

### 3. Output Parsing

Coder1 monitored each agent's terminal output:
```
"I'll create the login form..." → Status: Thinking
"Creating app/login/page.tsx" → Status: Writing, File: page.tsx
"Running tests..." → Status: Testing
"All tests passed!" → Status: Complete
```

This powered the real-time progress indicators in the dashboard.

## Troubleshooting

### "Claude CLI not found"

**Solution**:
```bash
# Verify Claude CLI is installed
which claude

# If not found, ensure Claude.app is installed and enabled
# Then restart terminal and Coder1 IDE
```

### Agents not spawning

**Solution**:
```bash
# Check git repository is initialized
git status

# Commit or stash any uncommitted changes
git stash

# Verify Claude Pro subscription is active
claude --help  # Should not error
```

### Port 3001 already in use

**Solution**:
```bash
# Kill existing process
lsof -ti :3001 | xargs kill -9

# Then restart
npm run dev
```

### AI Team button not showing CLI Puppeteer

**Solution**:
1. Check `.env.local` has `ENABLE_CLI_PUPPETEER=true`
2. Verify `CLAUDE_CLI_PATH` points to correct location
3. Restart development server
4. Check terminal output for "CLI Puppeteer: Enabled"
