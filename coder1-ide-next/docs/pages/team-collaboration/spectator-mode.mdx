# Spectator Mode

Watch your teammates' terminals in real-time. Perfect for pair programming, onboarding, and code reviews.

## Overview

Spectator Mode lets you see exactly what a teammate sees in their terminal — every command, every output, in real-time. It's like looking over their shoulder, but from anywhere.

## Sharing Your Terminal

Let teammates watch what you're doing.

### Start Sharing

1. Click the **Share Terminal** button in your terminal header
2. Or use the keyboard shortcut: `Cmd/Ctrl + Shift + T`

Your terminal now appears in the **Live Terminals** section of the Team Panel for all teammates.

When sharing, you'll see:

### Spectator Count

The badge shows how many teammates are currently watching your terminal.

### Stop Sharing

Click the **Stop Sharing** button or press `Cmd/Ctrl + Shift + T` again.

<Callout type="info" title="Privacy">
Only your terminal output is shared. Teammates cannot control your terminal or access your file system.
</Callout>

### Spectator Features

| Feature | Description |
|---------|-------------|
| **Real-time sync** | Output streams instantly via WebSocket |
| **Scroll lock** | Automatically follows new output |
| **Read-only** | You cannot type or control the terminal |
| **Branch context** | See which branch they're working on |

Click **Stop Watching** to return to your own terminal.

## Technical Details

### How It Works

1. **PTY capture**: Your terminal output is captured from the pseudoterminal
2. **Debounced streaming**: Output is batched every 50ms for efficiency
3. **WebSocket broadcast**: Data streams to spectators via Socket.IO
4. **Terminal rendering**: Spectators render output in a synchronized xterm.js instance

### Socket Events

| Event | Direction | Description |
|-------|-----------|-------------|
| `spectator:start` | Client → Server | Begin sharing your terminal |
| `spectator:stop` | Client → Server | Stop sharing |
| `spectator:join` | Client → Server | Start watching a terminal |
| `spectator:leave` | Client → Server | Stop watching |
| `spectator:output` | Server → Client | Terminal output broadcast |

### Bandwidth Usage

Terminal output is text-based and highly compressible:

| Activity | Bandwidth |
|----------|-----------|
| Idle terminal | ~0 KB/s |
| Normal typing | ~1-5 KB/s |
| Fast scrolling output | ~50-100 KB/s |
| Heavy log output | ~200+ KB/s |

<Callout type="info" title="Smart Buffering">
Spectator Mode uses intelligent buffering to minimize bandwidth while maintaining real-time feel.
</Callout>

## Limitations

- **Read-only**: Spectators cannot control the shared terminal
- **No history**: Joining mid-session shows only new output
- **Single terminal**: Only one terminal can be shared at a time
- **Same team**: Only team members can spectate

## Troubleshooting

### Terminal not appearing in Live Terminals

1. Verify you clicked "Share Terminal"
2. Check WebSocket connection (green dot in Team Panel)
3. Ensure teammate is on the same team

### Lag or delay in spectator view

1. Check internet connection
2. Reduce output-heavy operations
3. Try stopping and restarting the share

### Spectator count not updating

1. Refresh the page
2. Check if spectators are still connected
