## Environment Setup

Enable team features by setting these environment variables:

```bash
# Required for team features
NEXT_PUBLIC_ENABLE_TEAM_FEATURES=true

# Optional: Voice calls
NEXT_PUBLIC_ENABLE_VOICE_CALLS=true
LIVEKIT_API_KEY=your-livekit-key
LIVEKIT_API_SECRET=your-livekit-secret
LIVEKIT_URL=wss://your-livekit-server

# Optional: PR Dashboard
NEXT_PUBLIC_PR_DASHBOARD_ENABLED=true
GITHUB_CLIENT_ID=your-github-client-id
GITHUB_CLIENT_SECRET=your-github-client-secret

# Optional: Conflict Detection
NEXT_PUBLIC_CONFLICT_DETECTION_ENABLED=true
```

<Callout type="success" title="No Database Required">
