# Team Setup

Learn how to create a team, invite members, and manage roles and permissions.

## Prerequisites

Before setting up a team, ensure you have:

1. **Authenticated account** — You must be logged in to Coder1 IDE
2. **Team features enabled** — `NEXT_PUBLIC_ENABLE_TEAM_FEATURES=true` in your environment

## Creating a Team

### Step 1: Open the Team Panel

Click the **Team** icon in the right sidebar, or use the keyboard shortcut to open it.

### Step 2: Enter a Team Name

### Step 3: Click Create

Your team is instantly created and you become the **Owner**.

## Inviting Members

### Email Invitations

1. In the Team Panel, find the **Invite Member** section
2. Enter your teammate's email address
3. Click **Invite**
4. An invite link is copied to your clipboard automatically
5. Share the link with your teammate (Slack, email, etc.)

### Invitation States

| State | Description |
|-------|-------------|
| **Pending** | Invitation sent, waiting for teammate to accept |
| **Accepted** | Teammate has joined the team |
| **Expired** | Invitation link has expired (after 7 days) |

<Callout type="warning" title="Expired Invitations">
If an invitation expires, simply re-invite the teammate with a new email. Each invitation generates a unique, secure token.
</Callout>

## Understanding Roles

Teams have three roles with different permission levels:

### Permission Matrix

| Permission | Owner | Admin | Member |
|------------|:-----:|:-----:|:------:|
| View team members | Yes | Yes | Yes |
| View team knowledge | Yes | Yes | Yes |
| Share session summaries | Yes | Yes | Yes |
| Use team chat | Yes | Yes | Yes |
| Join voice calls | Yes | Yes | Yes |
| Create shared commands | Yes | Yes | Yes |
| Delete knowledge facts | Yes | Yes | Yes |
| Invite new members | Yes | Yes | No |
| Remove members | Yes | Yes | No |
| Change member roles | Yes | Yes | No |
| Delete the team | Yes | No | No |
| Transfer ownership | Yes | No | No |

### Syncing Team Knowledge

Click the **Sync** button to manually trigger a knowledge sync:

- **Push**: Sends your local insights to the team
- **Pull**: Fetches teammates' latest contributions

<Callout type="success" title="Automatic Sync">
Knowledge syncs automatically when you connect. Manual sync is useful after making significant discoveries you want to share immediately.
</Callout>

### Deleting a Team

<Callout type="error" title="Destructive Action">
Deleting a team is permanent and cannot be undone. All team data, including summaries, knowledge, and chat history, will be lost.
</Callout>

Only the **Owner** can delete a team:

1. Click the **Delete** button in the Team Panel header
2. Confirm in the dialog: "Delete team 'TeamName'? This cannot be undone."
3. The team is permanently removed

### Transferring Ownership

To transfer ownership to another member:

1. Contact the new owner to confirm they want the responsibility
2. The current owner promotes the member to owner role
3. The previous owner is automatically demoted to admin

Ownership transfer UI is planned for a future release. Currently, contact support for ownership transfers.

## Connection Status

The Team Panel shows your real-time connection status:

| Indicator | Meaning |
|-----------|---------|
|  Green dot | Connected to team sync server |
|  Yellow dot | Connection issues or reconnecting |
| Error banner | Detailed error message with retry option |

### Troubleshooting Connection Issues

**"Team sync unavailable"**
1. Check your internet connection
2. Verify `NEXT_PUBLIC_ENABLE_TEAM_FEATURES=true` is set
3. Ensure Supabase is configured correctly
4. Check browser console for WebSocket errors

**Teammates not appearing online**
1. Ask them to refresh their page
2. Check if they're on the same team (team ID matches)
3. Verify Socket.IO connection in Network tab
