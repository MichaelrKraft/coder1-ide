# Real-time Collaboration

See who's online, chat with teammates, and hop on voice calls — all without leaving the IDE.

## Presence Indicators

Know who's working right now at a glance.

Each team member shows their connection status:

| Indicator | Meaning |
|:---------:|---------|
| Green dot | Online and connected |
| Gray dot | Offline or disconnected |
| Yellow dot | Reconnecting (temporary) |

### How Presence Works

Presence updates happen automatically via WebSocket:

1. **Join**: When you open Coder1, your status broadcasts to teammates
2. **Heartbeat**: Every 30 seconds, presence is refreshed
3. **Leave**: When you close the tab or disconnect, teammates see you go offline

<Callout type="info" title="Instant Updates">
Presence changes appear within 1-2 seconds. No polling or manual refresh needed.
</Callout>

### How Colors Are Assigned

Colors are **deterministic** — the same user ID always gets the same color. This is achieved by hashing the user ID and mapping it to one of 12 colors.

### Where Colors Appear

- **Presence list** — Avatar background
- **Activity feed** — User indicators
- **Chat messages** — Avatar circle
- **Cursor selections** — Text highlight (15% opacity)
- **Voice call tiles** — Participant border

<Callout type="info" title="Consistent Identity">

</Callout>

## Environment Setup

Enable real-time features with these environment variables:

```bash
# Core team features (required)
NEXT_PUBLIC_ENABLE_TEAM_FEATURES=true

# Voice calls (optional)
NEXT_PUBLIC_ENABLE_VOICE_CALLS=true
LIVEKIT_API_KEY=your-livekit-api-key
LIVEKIT_API_SECRET=your-livekit-api-secret
LIVEKIT_URL=wss://your-livekit-server.livekit.cloud
```

### LiveKit Setup

1. Create an account at [livekit.cloud](https://livekit.cloud)
2. Create a new project
3. Copy your API key, secret, and WebSocket URL
4. Add them to your environment variables

## Socket Events Reference

For developers extending team features:

### Presence Events

| Event | Direction | Payload |
|-------|-----------|---------|
| `team:presence:join` | Server → Client | `{ userId, name, role }` |
| `team:presence:leave` | Server → Client | `{ userId }` |
| `team:presence:update` | Server → Client | `{ members: [...] }` |

### Activity Events

| Event | Direction | Payload |
|-------|-----------|---------|
| `team:activity:commit` | Client → Server | `{ branch, message }` |
| `team:activity:push` | Client → Server | `{ branch, remote }` |
| `team:activity:branch` | Client → Server | `{ from, to }` |

### Chat Events

| Event | Direction | Payload |
|-------|-----------|---------|
| `team:chat:message` | Bidirectional | `{ userId, content, timestamp }` |
| `team:chat:typing` | Client → Server | `{ userId }` |
