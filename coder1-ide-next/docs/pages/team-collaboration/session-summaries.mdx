# Session Summaries

Share your coding sessions with teammates. Get AI-generated briefings to stay in sync.

## Sharing a Summary

### Step 1: Complete Your Session

When you're ready to share what you've accomplished:

1. Click the **Share Summary** button in the Status Bar
2. Or use the keyboard shortcut: `Cmd/Ctrl + Shift + S`

### Step 2: Review Your Summary

Coder1 automatically generates a summary from your session, including:

- **Title** — Brief description of what you accomplished
- **Session Type** — Category of work (see below)
- **Branch** — The git branch you worked on
- **Files Modified** — Count of files you touched
- **Key Insights** — AI-extracted learnings from your session

### Step 3: Share with Team

Click **Share with Team** to broadcast your summary. Teammates receive:

- A toast notification with your name
- An unread badge on the Summaries tab
- Real-time update in their summary list

<Callout type="info" title="Auto-Sync">
Summaries sync automatically when teammates are online. If someone is offline, they'll see new summaries when they reconnect.
</Callout>

## Session Types

Each summary has a type that helps teammates quickly understand the work:

| Type | Description |
|------|-------------|
| **bug-fix** | Fixed a bug or resolved an issue |
| **feature-dev** | Built new functionality |
| **refactoring** | Improved code structure without changing behavior |
| **exploration** | Researched, investigated, or experimented |
| **general** | Documentation, configuration, or other work |

### Automatic Detection

Coder1 suggests a session type based on:
- Your git branch name (`fix/`, `feature/`, `refactor/`)
- Types of files modified
- Content of your changes

You can always override the suggested type before sharing.

- New summaries were added after the initial generation
- You want a different summarization perspective

## Lazy Loading

The Summaries tab uses pagination to keep things fast.

- **Initial load**: 10 most recent summaries
- **Load more**: Click "Load more" to fetch the next 10
- **Pinned summaries**: Always shown at top, regardless of age

<Callout type="success" title="Performance">
Even teams with 1000+ summaries load quickly because only visible summaries are fetched.
</Callout>

## Real-time Updates

Summaries update in real-time via Socket.IO:

| Event | Description |
|-------|-------------|
| `summary:shared` | New summary from teammate |
| `summary:pinned` | Summary was pinned/unpinned |
| `summary:updated` | Summary content was edited |

You never need to refresh — new summaries appear automatically.
