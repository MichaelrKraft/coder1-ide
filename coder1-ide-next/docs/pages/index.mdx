## Quick Start

Get started in 60 seconds:

<Steps>
  <Step title="Clone the Repository">
```bash
git clone https://github.com/MichaelrKraft/coder1-ide.git
cd coder1-ide/coder1-ide-next
```
  </Step>

  <Step title="Install Dependencies">
```bash
npm install
```
  </Step>

  <Step title="Start Coding">
```bash
npm run dev
# Open http://localhost:3001/ide
```
  </Step>
</Steps>

<Callout type="success">
No API keys required. Start coding immediately!
</Callout>

## Key Features

### 🎯 AI Team Dashboard
Visual mission control for your AI agents. See real-time progress, status, and activity for each agent working on your project.

### 💻 Full IDE Experience
Monaco Editor (VSCode engine), integrated terminal with full PTY support, file explorer, live preview, and more.

### 🔄 Session Management
Checkpoints, AI-generated summaries, and seamless handoffs between human and AI coding sessions.

### 🎤 Voice Input
Speak your requirements naturally. Coder1 understands and executes.

### 📊 Context Visibility
See exactly what context AI has access to. Token counting, memory insights, and optimization suggestions.
