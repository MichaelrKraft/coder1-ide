### Intelligent Retrieval

When Claude needs context, the system:

1. **Analyzes current task** - Understands what you're trying to accomplish
2. **Retrieves relevant past decisions** - Finds related conversations and code
3. **Injects into AI prompt** - Provides seamless context
4. **Maintains consistency** - Ensures architectural coherence
