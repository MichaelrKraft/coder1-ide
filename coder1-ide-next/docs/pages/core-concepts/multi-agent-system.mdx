## Overview

Coder1's multi-agent system spawns **real Claude CLI instances** that work in **separate git worktrees**, enabling true parallel development without merge conflicts.

## How It Works

<Steps>
  <Step title="User Clicks 'AI Team' Button">
    The AI Team button in the terminal header triggers the orchestration system.
    
    A modal appears allowing you to select agent roles and provide task descriptions.
  </Step>

  <Step title="System Creates Git Worktrees">
    For each agent, Coder1 creates an isolated git worktree:
    
```bash
# Each agent gets its own workspace
git worktree add .claude-parallel-dev/team-xyz/frontend -b claude-agent/team-xyz/frontend
git worktree add .claude-parallel-dev/team-xyz/backend -b claude-agent/team-xyz/backend
git worktree add .claude-parallel-dev/team-xyz/testing -b claude-agent/team-xyz/testing
```
  </Step>

  <Step title="Claude CLI Processes Spawn">
    Real Claude Code CLI processes are spawned via PTY (pseudo-terminal):
    
```typescript
const agent = spawn('/opt/homebrew/bin/claude', [], {
  cwd: worktreePath,
  env: { ...process.env }
});
```
    
    Each process is a **real Claude instance**, not a simulation.
  </Step>

  <Step title="Visual Dashboard Updates">
    The AI Team Dashboard appears, showing real-time progress for each agent:
    
    - **Status**: Thinking, Writing, Testing, Idle, Error, Complete
    - **Progress**: 0-100% based on terminal output analysis
    - **Current File**: Which file the agent is working on
    - **Time Elapsed**: How long the agent has been active
    - **Branch**: Git branch for that agent's work
  </Step>

  <Step title="Agents Work Independently">
    Each agent:
    - Reads/writes files in its worktree
    - Makes commits to its branch
    - Streams output to its terminal tab
    - Reports progress via WebSocket
    
    **All agents work simultaneously** without interfering with each other.
  </Step>
</Steps>

## Merging Agent Work

When agents complete, you can review and merge their branches:

```bash
# View what each agent did
git log claude-agent/team-xyz/frontend --oneline
git log claude-agent/team-xyz/backend --oneline
git log claude-agent/team-xyz/testing --oneline

# Review changes with diff
git diff main..claude-agent/team-xyz/frontend

# Merge frontend agent's work
git checkout main
git merge claude-agent/team-xyz/frontend

# Repeat for other agents
git merge claude-agent/team-xyz/backend
git merge claude-agent/team-xyz/testing

# Clean up branches
git branch -d claude-agent/team-xyz/frontend
git branch -d claude-agent/team-xyz/backend
git branch -d claude-agent/team-xyz/testing

# Remove worktrees
git worktree remove .claude-parallel-dev/team-xyz/frontend
git worktree remove .claude-parallel-dev/team-xyz/backend
git worktree remove .claude-parallel-dev/team-xyz/testing
```

<Callout type="warning" title="Best Practice">
Always review each agent's changes before merging. Use `git diff` to inspect modifications.
</Callout>

## Troubleshooting

### Agent spawn fails

**Symptom**: "Failed to create worktree"

**Solutions**:
1. Ensure you're in a git repository
2. Commit or stash uncommitted changes
3. Check available disk space

```bash
git status
git stash
df -h
```

### Claude CLI not found

**Symptom**: "Claude CLI not found at /opt/homebrew/bin/claude"

**Solutions**:
1. Install Claude.app
2. Enable Claude Code from menu
3. Verify installation: `claude --version`

### Memory issues on Render

**Symptom**: Agents crash with "Out of memory"

**Solutions**:
1. Reduce max concurrent agents to 2-3
2. Set `MAX_PARALLEL_AGENTS=3` in `.env.local`
3. Consider upgrading Render plan
