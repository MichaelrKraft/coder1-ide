## What is Claude Code?

Claude Code is Anthropic's official CLI tool that brings Claude's capabilities directly into your terminal. It's included with Claude Pro (\$20/month) and provides:

- **Deep Code Understanding**: Claude analyzes entire codebases, not just single files
- **Autonomous Actions**: Can read, write, and modify files independently
- **Terminal Access**: Runs commands and tests code directly
- **Context Persistence**: Maintains conversation history across sessions

## The CLI Puppeteer System

Coder1's revolutionary approach: **spawn real Claude CLI processes** and orchestrate them via PTY (pseudo-terminals).

### How It Works

<Steps>
  <Step title="User Clicks 'AI Team'">
    The AI Team button triggers the orchestration system with selected agent roles.
  </Step>
  
  <Step title="Git Worktrees Created">
    Each agent gets an isolated git worktree on its own branch:
    
```bash
git worktree add .claude-parallel-dev/team-xyz/frontend \
  -b claude-agent/team-xyz/frontend
```
  </Step>
  
  <Step title="Claude CLI Spawned">
    Real Claude processes are spawned via PTY:
    
```typescript
const pty = spawn('/opt/homebrew/bin/claude', [], {
  cwd: worktreePath,
  env: {
    ...process.env,
    CLAUDE_AGENT_ROLE: 'frontend',
    CLAUDE_TASK: 'Build login component'
  }
});
```
  </Step>
  
  <Step title="Task Injection">
    The task is sent to Claude's input stream:
    
```typescript
pty.write(`Build a login component with email/password fields,
validation, and form submission to /api/auth/login\n`);
```
  </Step>
  
  <Step title="Output Monitoring">
    Agent output is parsed in real-time:
    
```typescript
pty.onData((data) => {
  // Parse for progress indicators
  if (data.includes('Creating file')) {
    updateProgress('Writing files', 60);
  }
  
  // Detect completion
  if (data.includes('Task complete')) {
    markAgentComplete();
  }
});
```
  </Step>
</Steps>

## Agent Coordination

Multiple Claude instances work independently without conflicts thanks to git worktrees:

```bash
# Three agents working simultaneously
Frontend Agent → .claude-parallel-dev/team-xyz/frontend/
Backend Agent  → .claude-parallel-dev/team-xyz/backend/
Testing Agent  → .claude-parallel-dev/team-xyz/testing/

# Each on its own branch
frontend: claude-agent/team-xyz/frontend
backend:  claude-agent/team-xyz/backend
testing:  claude-agent/team-xyz/testing

# Zero merge conflicts during development ✨
```

<Callout type="info" title="Git Worktrees">
Git worktrees allow multiple working directories from the same repository. Each agent works in complete isolation until merge time.
</Callout>

  <Step title="Install Claude.app">
    Download Claude desktop app from [claude.ai](https://claude.ai)

  </Step>
  
  <Step title="Enable Claude Code">
    In Claude.app menu bar, click:

  </Step>
  
  <Step title="Verify Installation">
```bash
# Check Claude CLI is available
claude --version

# Should output: claude-code vX.X.X
```
  </Step>
  
  <Step title="Configure Coder1">
```bash
# Enable CLI Puppeteer in Coder1
echo "ENABLE_CLI_PUPPETEER=true" >> .env.local
echo "CLAUDE_CLI_PATH=/opt/homebrew/bin/claude" >> .env.local

# Restart Coder1
npm run dev
```
  </Step>
</Steps>

## Troubleshooting

### Claude CLI Not Found

**Symptom**: "Claude CLI not found at /opt/homebrew/bin/claude"

**Solutions**:
1. Verify Claude.app is installed
2. Enable Claude Code in menu: Claude → Enable Claude Code
3. Check installation:
```bash
which claude
# Should output path to claude binary
```
4. Set custom path if non-standard location:
```bash
CLAUDE_CLI_PATH=$(which claude)
```

### Agent Spawn Failures

**Symptom**: "Failed to spawn agent: Error: spawn ENOENT"

**Solutions**:
1. Ensure git repository initialized:
```bash
git status  # Should not error
```
2. Commit or stash changes:
```bash
git stash
```
3. Check disk space:
```bash
df -h
```

### Agents Not Progressing

**Symptom**: Agent stuck at "Thinking..." for >5 minutes

**Solutions**:
1. Check agent logs in AI Team Dashboard
2. Verify Claude Pro subscription active
3. Check for rate limiting (rarely occurs with CLI)
4. Restart agent:
```bash
# From AI Team Dashboard, click "Restart" button
```

### Output Parsing Issues

**Symptom**: Progress not updating despite agent activity

**Solutions**:
1. Enable verbose logging:
```bash
DEBUG_CLI_PUPPETEER=true npm run dev
```
2. Check for unexpected output format in logs
3. Report pattern to GitHub issues for parser improvements
