# Monaco Editor

<Callout type="success" title="VSCode Power">
Coder1 uses **Monaco Editor** - the same editor that powers Visual Studio Code.
</Callout>

The Monaco Editor provides a professional code editing experience with syntax highlighting, IntelliSense, and advanced editing features for all major programming languages.

## Key Features

### Syntax Highlighting

Full syntax highlighting support for:
- JavaScript/TypeScript
- Python
- Java
- C/C++
- Go
- Rust
- HTML/CSS
- JSON/YAML
- Markdown
- And 50+ more languages

### IntelliSense & Autocomplete

Smart code completion powered by:
- Language servers
- Type definitions
- Context-aware suggestions
- Import auto-completion

### Code Navigation

Efficient code navigation with:
- Go to Definition (F12)
- Find All References (Shift+F12)
- Peek Definition (Alt+F12)
- Symbol search (Ctrl+Shift+O)

### Multi-Cursor Editing

Advanced editing capabilities:
- Multiple cursors (Alt+Click)
- Column selection (Shift+Alt+Drag)
- Find and replace with regex
- Smart bracket matching

## Editor Settings

### Theme

Coder1 uses a dark theme optimized for long coding sessions:
- **Tokyo Night** color scheme
- Reduced eye strain
- High contrast for readability

### Font Configuration

Default configuration:
- Font: Monaco, Menlo, Consolas
- Size: 14px
- Line height: 1.5
- Ligatures: Enabled

## Keyboard Shortcuts

| Action | Windows/Linux | macOS |
|--------|--------------|-------|
| Save File | Ctrl+S | Cmd+S |
| Find | Ctrl+F | Cmd+F |
| Replace | Ctrl+H | Cmd+H |
| Comment Line | Ctrl+/ | Cmd+/ |
| Format Document | Shift+Alt+F | Shift+Option+F |
| Command Palette | Ctrl+Shift+P | Cmd+Shift+P |

## Integration with Claude

The editor integrates seamlessly with Claude Code:
- Claude can read and modify files directly
- Changes appear in real-time
- Full context awareness
- Syntax-aware edits

- Smooth scrolling
