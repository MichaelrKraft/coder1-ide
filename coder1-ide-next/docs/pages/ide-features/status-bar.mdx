# Status Bar

<Callout type="success" title="Quick Access Hub">
The Status Bar provides instant access to essential IDE controls, session information, and AI features.
</Callout>

The Status Bar is your command center for managing sessions, checkpoints, and AI agent teams. It sits at the bottom of the IDE and gives you real-time visibility into your development environment.

## Key Features

### Session Management

View and control your current development session:
- **Session ID** - Unique identifier for current session
- **Session Duration** - Active time tracking
- **Last Activity** - When the session was last updated
- **Quick Actions** - Session controls at your fingertips

### AI Team Controls

Spawn and manage AI agent teams:
- **AI Team Button** - Launch multi-agent development teams
- **Agent Status** - Real-time agent activity indicators
- **Team Management** - Control active agent workflows
- **Cost Tracking** - Monitor API usage and costs

### Session Summary

Generate comprehensive session reports:
- **Summary Button** - Create detailed session documentation
- **Export Options** - Markdown, JSON, or HTML formats
- **Automatic Capture** - Logs all activities and changes
- **AI-Enhanced** - Intelligent summarization of work done

### Checkpoint System

Save and restore development states:
- **Create Checkpoint** - Save complete IDE state
- **Restore Checkpoint** - Roll back to previous states
- **Checkpoint List** - Browse all saved checkpoints
- **Metadata Display** - View checkpoint details and timing

## Status Indicators

## Checkpoint Management

### Creating Checkpoints

Save complete IDE state:
- All open files and editors
- Terminal sessions and history
- Current working directory
- Git repository state
- UI layout and settings

### Restoring Checkpoints

Roll back to previous states:
- Browse checkpoint history
- Preview checkpoint contents
- Selective restoration options
- Preserve or replace current state

<Callout type="warning">
Restoring a checkpoint will replace your current IDE state. Save important changes before restoring.
</Callout>

### Checkpoint Metadata

Each checkpoint includes:
- **Timestamp**: When checkpoint was created
- **Session ID**: Associated development session
- **File Count**: Number of tracked files
- **Description**: Optional custom label
- **Size**: Storage space used

## Configuration

### Status Bar Settings

Customize appearance and behavior:
- **Position**: Bottom (default) or top
- **Height**: Compact or expanded
- **Auto-hide**: Show on mouse hover
- **Notifications**: Enable/disable alerts

### Session Settings

Configure session behavior:
- **Auto-save**: Save changes automatically
- **Summary Frequency**: How often to generate summaries
- **Checkpoint Interval**: Automatic checkpoint creation
- **Session Timeout**: Inactivity timeout duration

## Performance

The Status Bar is optimized for minimal overhead:
- **~5ms update latency** for status changes
- **Lazy loading** of checkpoint data
- **Efficient polling** for agent status
- **Minimal memory footprint**

## Troubleshooting

### Session summary button not working

1. Check that you have active session
2. Verify API keys are configured
3. Check browser console for errors
4. Try refreshing the page

### Checkpoint restoration fails

1. Verify checkpoint file exists
2. Check file permissions
3. Ensure sufficient disk space
4. Try restoring to new session

### AI Team button disabled

1. Confirm ANTHROPIC_API_KEY is set
2. Check API key validity
3. Verify sufficient API credits
4. Review API rate limits

```typescript

statusBar.addItem({
  id: 'custom-widget',
  text: 'Custom Status',
  tooltip: 'My custom information',
  command: 'my.command'
});

// Update status text
statusBar.updateItem('custom-widget', {
  text: 'Updated Status'
});
```
