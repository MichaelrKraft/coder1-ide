## Overview

The AI Team Dashboard is your command center for monitoring multiple AI agents working in parallel. It provides real-time status updates, progress tracking, and detailed insights into each agent's activities.

<Callout type="success" title="Zero Configuration">
The dashboard automatically appears when you spawn AI agents - no setup required.

## WebSocket Architecture

The dashboard uses Socket.IO for real-time updates:

```typescript
// Client-side connection
const socket = io('http://localhost:3001');

// Subscribe to agent status updates
socket.on('agent:progress', ({ agentId, progress, status, file }) => {
  updateDashboard(agentId, { progress, status, file });
});

// Subscribe to agent completion
socket.on('agent:complete', ({ agentId, summary }) => {
  markAgentComplete(agentId);
  showCompletionNotification(summary);
});

// Subscribe to agent errors
socket.on('agent:error', ({ agentId, error }) => {
  showErrorState(agentId, error);
});
```

## Troubleshooting

### Dashboard not updating

**Symptom**: Agent progress frozen despite terminal activity

**Solutions**:
1. Check WebSocket connection: Look for green "Connected" indicator
2. Refresh page to reconnect WebSocket
3. Check browser console for connection errors
4. Verify firewall isn't blocking WebSocket connections

### Incorrect progress percentages

**Symptom**: Progress shows 100% but agent still working

**Solutions**:
1. Progress is estimated based on output parsing
2. Unusual output patterns may trigger false completion
3. Check agent terminal for actual status
4. Report pattern to GitHub for parser improvements

### Agent status shows "Error" but terminal looks fine

**Symptom**: Error state without visible errors in terminal

**Solutions**:
1. Scroll up in terminal to find error message
2. Click "View Terminal" to see full output
3. Agent may have recovered automatically
4. Restart agent if truly stuck
