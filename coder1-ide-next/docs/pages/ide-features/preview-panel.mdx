# Live Preview

<Callout type="success" title="Real-Time Visualization">
See your changes instantly with hot-reload preview that updates as you code.
</Callout>

The Live Preview panel provides real-time visualization of your web applications, automatically refreshing as you make changes to HTML, CSS, and JavaScript files.

## Key Features

### Instant Hot Reload

Changes appear immediately:
- **Sub-second Updates** - See changes in ~200ms
- **Smart Refresh** - Only reloads what changed
- **No Manual Refresh** - Automatic detection of file changes
- **State Preservation** - Maintains scroll position and form data

### Multi-Device Preview

Test responsive designs:
- **Desktop View** - Standard desktop browser size
- **Tablet View** - iPad and tablet dimensions
- **Mobile View** - iPhone and mobile device sizes
- **Custom Dimensions** - Define your own viewport sizes

### Browser Sync

Synchronized testing:
- **Multiple Browsers** - Test across Chrome, Firefox, Safari
- **Scroll Sync** - Synchronized scrolling across devices
- **Click Sync** - Mirror interactions across previews
- **Form Sync** - Synchronized form inputs

## Hot Reload Technology

### How It Works

<div className="bg-slate-800/50 border border-slate-700 rounded-lg p-6 my-8">
```
File Change Detection
        ↓
    Change Analysis
        ↓
 Selective Module Update
        ↓
    DOM Patch
        ↓
  State Preservation
        ↓
   Visual Update (~200ms)
```
</div>

**Technology Stack**:
- **File Watcher**: Monitors file system for changes
- **Module Bundler**: Webpack/Vite hot module replacement
- **WebSocket**: Real-time change notifications
- **Virtual DOM**: Efficient DOM updates

### Supported File Types

Instant reload for:
- **HTML** - Structure changes
- **CSS/SCSS** - Style updates without reload
- **JavaScript** - Module hot replacement
- **Images** - Asset updates
- **JSON** - Configuration changes

### State Preservation

Maintains application state during reload:
- Form input values
- Scroll positions
- Expanded/collapsed sections
- Active tabs and modals
- Component state

## Troubleshooting

### Preview not updating

1. Check if auto-refresh is enabled
2. Verify file changes are being saved
3. Clear browser cache (Ctrl+Shift+R)
4. Restart development server

### Slow preview performance

1. Disable unnecessary browser extensions
2. Reduce preview zoom level
3. Close unused device previews
4. Check for memory leaks in console

### CORS errors in console

1. Ensure development server allows CORS
2. Check API endpoint configuration
3. Use proxy configuration if needed
4. Verify browser security settings

<Callout type="warning">
Some features (geolocation, notifications) may require HTTPS even in development mode.
</Callout>
