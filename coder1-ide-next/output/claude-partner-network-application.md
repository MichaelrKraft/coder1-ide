### Product Description (2–3 sentences, for Powered by Claude listing)
```
Coder1 IDE is a web-based development environment built exclusively for Claude Code users. It provides a local-first, secure bridge into users' own Claude Code sessions — adding real-time collaboration (like Google Docs for Claude Code), persistent long-term memory across sessions, and an autonomous AI assistant layer. Unlike cloud IDEs or plugins, Coder1 works alongside the user's existing Claude Code subscription without requiring new infrastructure or a separate AI account.
```

### How We Use Claude (technical details)
```
Claude Code CLI is the core AI engine powering Coder1 IDE. All code generation, agentic task execution, and debugging flows through Claude Code running locally on the user's machine via a secure WebSocket bridge. Coder1 adds the IDE interface (Monaco editor, xterm.js terminal, Monaco-based file tree), session checkpointing and restore, real-time multi-user collaboration via Socket.IO, and a persistent memory system that surfaces insights across Claude Code sessions. We use claude-sonnet-4-6 and claude-haiku-4-5 via the Anthropic SDK for session summarization, memory detection, and autonomous agent features.
```

### Target Market / Use Case
```
Claude Code power users, vibe coders, indie developers, and development teams who want to build faster with Claude Code. We specifically serve users who want: (1) team collaboration on Claude Code sessions, (2) persistent memory across sessions, (3) an IDE-class interface rather than terminal-only access, and (4) local-first security where code never leaves their machine.
```

### Key Differentiators vs. Competitors (Cursor, Windsurf, etc.)
```
1. Local-first security — bridges into the user's own Claude Code sessions; no cloud code execution
2. Real-time multi-user collaboration (Google Docs-style) for Claude Code sessions
3. Persistent long-term memory across sessions using Claude for summarization
4. Works with the user's existing Claude Code subscription — not a replacement
5. Full IDE (Monaco editor + xterm.js terminal + file tree) rather than a plugin or extension
6. Agentic AI assistant that can operate autonomously using the user's computer
```
